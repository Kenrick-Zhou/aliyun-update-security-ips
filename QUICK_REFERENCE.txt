💡 TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  • Never commit .env file
  • Create whitelist groups before use
  • Set reasonable check intervals (60-300s)
  • Monitor logs regularly
  • Rotate AccessKey periodically

⚠️  TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Cannot get IP?
    → Check network connection
    → Try different IP check services

  AccessKey error?
    → Verify credentials in .env
    → Check AccessKey permissions

  Instance not found?
    → Verify instance ID format
    → Check region configuration

  See FAQ.md for more solutions
